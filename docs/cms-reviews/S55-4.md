# S55 review packet — Slice 4 (increment): section library, global node, composition tokens

**Work item (audit):** Slice 4 — broader section library, global sections,
richer tokens.
**Exit evidence target:** materially different layouts from the editor, not
color presets.

## What was built
- **Two new section types, registry-first**: `image_with_text` (media +
  required alt, side toggle, heading/text/CTA — a genuinely different
  two-column layout) and `product_rail` (bound to ONE chosen collection,
  featured/pinned order, per-instance limit, View-all link). One registry
  declaration each drives validation, per-instance data resolution
  (collection_products source, batched by (collection, limit)), the shared
  renderer, and the Designer's generated inspector (new control kinds:
  media → MediaPicker with alt backfill, collection → CollectionPicker,
  choice → Select). Renderer-side kind filters now read the registry — the
  hard-coded lists that would have silently dropped new kinds are gone.
- **Global section in the designer**: the announcement bar is a pinned
  node (enable/text/link, own CAS + conflict handling, highlight syncs to
  the storefront header's data-sec).
- **Composition tokens**: brand gains `button_shape` (pill/rounded/square →
  --btn-radius on storefront CTAs) and `section_spacing` (compact/regular/
  airy → --section-pad-y on home sections + hero rhythm), validated,
  live-previewed in Brand, release-governed like all brand tokens.
  **Defaults reproduce the pre-S55 hardcoded look exactly** (pill, 3.5rem),
  so every existing tenant renders byte-identically until they choose.
- **Forms-editor safety**: HomeEditor shows registry labels and renders
  designer-only kinds as a neutral "edit in the Designer" card whose
  move/hide/duplicate/remove still work; round-tripping verified at the
  save-path level (only client keys stripped).
