## Source findings (verified)
Product modules/badges (product_overrides), collection pins
(collection_overrides), upsell placements and slug redirects applied the
moment they were saved — outside preview, outside the release diff, outside
rollback. mediaUsage scanned only drafts + the LIVE release (scheduled and
historical releases unprotected) and never searched derivative URLs.

## Changes
- **Snapshot v2** (lib/releases.js): the envelope gains product_overrides,
  collection_pins, placements, redirects (normalized, sorted, strict reads —
  only "no such table" is empty). v1 releases remain fully renderable.
- **Pure selection helpers** (lib/content/presentation.js, node-safe):
  presentationProductOverride/CollectionPins/Placements/SlugRedirect return
  the frozen set from a v2 release, or null for v1 = "fall back to the live
  tables" — exactly what v1 releases were reviewed under.
- **Resolvers** (lib/content/resolve.js): resolvedProductOverride,
  resolvedCollectionPins, resolvedPdpPairs, resolvedCartUpsell,
  resolvedSlugRedirect — drafts/preview read tables, live reads the
  snapshot. Call sites swapped: PDP (override + pairs), /api/upsell (cart
  slot), journal slug redirect, collection page pin order (getProductsIn
  Collection gains an injected `pins`; getPdpPairs/getCartUpsell gain
  injected `placementRows`; collectionPinsByHandle exported). The pairs
  AUTO fallback (shared collections) stays a live catalog computation —
  commerce facts are never snapshotted.
- **Diff + labels**: releaseDiff reports overrides/pins/placements/redirects
  items (linked to their editors), plus a one-time "Publishing upgrade"
  item when the live release is v1 (the envelope change alone moves the
  hash; naming it beats an unexplained dirty state). For a v1 live release
  the four sets are not diffed against it (they were live-on-save then — a
  false "edited" on every tenant would be noise).
- **mediaUsage**: scans the asset AND its derivatives (parent_id), across
  drafts, product-module HTML, and EVERY release row — live, scheduled and
  retained — labelled accordingly. Delete remains two-step force.
- **Admin honesty**: Overview/Upsells/Product-pages copy flips to
  draft-until-publish; only site identity remains apply-immediately.
